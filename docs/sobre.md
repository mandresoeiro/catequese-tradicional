# Sobre o projeto

Este site é um projeto pessoal de estudo e organização da **Catequese Tradicional**, construído aula por aula.

## Objetivo editorial

Transformar os registros de estudo em um material coerente e progressivo que, no futuro, possa servir de base para um **livro de estudo**.

## Regra de cada aula

Cada aula deve conter:

- resumo essencial;
- estudo por blocos;
- mapa mental;
- pontos para memorizar;
- dicionário da aula;
- perguntas e respostas de revisão;
- revisão ativa;
- pontos para aprofundamento;
- resumo para treino em vídeo.

## Método de estudo

O material foi pensado para permitir quatro etapas simples:

1. **Ler** — compreender o resumo e os blocos principais.
2. **Relembrar** — tentar explicar o assunto sem consultar o texto.
3. **Testar** — responder ao questionário objetivo.
4. **Revisar** — voltar apenas aos conceitos que ainda não ficaram claros.

## Observação

Os resumos procuram preservar a estrutura e os conceitos apresentados nas aulas. Quando houver afirmações históricas que precisem de verificação externa, elas devem ser identificadas como pontos para aprofundamento, em vez de serem tratadas automaticamente como fatos confirmados.
